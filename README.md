# auto-x — X (Twitter) 自动回关

纯浏览器插件，**无需后端 / API Key**。支持 **Chrome · Edge · Firefox** 等。当前版本 **0.3.0**。

## 功能

1. **登录检测**：未登录显示「登录 X 账户」；已登录显示「连接」
2. **连接账户**：连接成功后展示当前账号（昵称 / @handle / 头像）
3. **开始 / 停止自动关注**：按钮在「开始自动关注」与「🛑 停止」之间切换
4. **后台持续运行**：关闭弹窗 **不会** 停止自动关注（由 background + alarms 维持）
5. **不抢操作**：自动关注走 GraphQL API，不模拟点击页面按钮；仅在你主动「同步粉丝/关注」时才翻页
6. **结果明细**：弹窗展示成功数/名单、失败数/名单，并在控制台打印 `✓` / `✗`

## 安装

### Chrome / Edge / Chromium

1. 打开 `chrome://extensions/`（Edge：`edge://extensions/`）
2. 开启「开发者模式」
3. 「加载已解压的扩展程序」→ 选择本仓库根目录
4. 打开并登录 `x.com`，点击工具栏图标按提示 **连接**

### Firefox

1. 打开 `about:debugging#/runtime/this-firefox`
2. 「临时载入附加组件」→ 选择本目录下的 `manifest.json`
3. 打开并登录 `x.com`，点击工具栏图标 **连接**

## 使用流程

```
打开 X 并登录 → 插件弹窗点「连接」→（建议）同步粉丝/关注
→ 点「开始自动关注」→ 可关闭弹窗，后台继续
→ 再打开弹窗查看成功/失败名单 → 需要时点「🛑 停止」
```

| 步骤 | 说明 |
|------|------|
| 登录 | 未登录时点「登录 X 账户」打开登录页 |
| 连接 | 绑定当前浏览器里已登录的 X 账号 |
| 同步 | 建立本地粉丝/关注库（会打开列表页自动翻页） |
| 开始自动关注 | 对「粉了你但你未回关」的用户按间隔回关 |
| 停止 | 立即停止排队与执行；关闭弹窗 ≠ 停止 |

## 设置项

弹窗 → 「设置」：

| 设置 | 默认 | 说明 |
|------|------|------|
| 最小间隔 | 60 秒 | 两次回关之间的等待 |
| 每日上限 | 50 | 当天最多成功回关数 |

## 注意

- 首次回关前，建议在 X 上 **手动关注一次**，让插件学习 Follow 接口 hash（之后会本地记住）
- 自动化有平台风控风险，请保守设置
- 数据仅存 `chrome.storage.local` / 浏览器本地，清除扩展数据会丢失
- `world: "MAIN"` 需要较新的浏览器（Chrome 111+ / 近年 Firefox）

## 目录结构

```
manifest.json
icons/
src/
  background.js      # 决策 / 队列 / 连接态（关弹窗仍运行）
  content.js         # 登录检测、桥接
  injector.js        # MAIN world 拦截 GraphQL + 执行 Follow
  lib/store.js       # 本地存储
  lib/browser.js     # 跨浏览器 API 垫片
  popup/             # 登录 / 连接 / 启停 / 结果 UI
  options/           # 间隔与上限
```
