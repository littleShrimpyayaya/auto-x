📋 如何连接 X 账号
  1. 打开 x.com 并登录你的账号
  2. 按 F12 打开开发者工具
  3. Chrome / Edge：点击 Application（应用）标签 → 左侧 Cookies → x.com
    Firefox：点击 Storage（存储）标签 → 左侧 Cookies → https://x.com
  4. 在右侧列表中找到 auth_token，双击 Value 列复制
  5. 同样找到 ct0，复制其 Value
  6. 将两个值粘贴到下方输入框，点击 Connect
